This portfolio represents my approach to digital design — combining aesthetic minimalism with high-end interactive elements.
Every section is crafted to feel dynamic, engaging, and intuitive.

The goal of this project is to:

Showcase my design and development skills
Create a memorable first impression
Demonstrate advanced frontend interaction techniques
🎯 Key Features
🌀 Multi-Axis Tilt Interaction

Cards respond to cursor movement using 3D tilt effects, creating a sense of depth and realism.

🔁 Flip Card System

Interactive project cards flip to reveal additional details, improving content density without clutter.

⚡ Smooth Animations

Powered by GSAP / CSS animations, ensuring fluid transitions and professional motion design.

🎮 Gamified UI Elements

Inspired by game design principles, the UI includes interactive components that make browsing engaging.

🌑 Modern Dark Theme

A clean, dark aesthetic with subtle highlights for a premium look and reduced eye strain.

📱 Responsive Design

Optimized for all devices — desktop, tablet, and mobile.

🧠 Design Philosophy

This portfolio follows a “Less but Better + Interaction First” approach:

Clarity over clutter
Motion with purpose
Depth over flat design
User engagement through interaction

The aim is to create an interface that feels alive, not static.
